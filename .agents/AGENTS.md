# Project-Specific Rules for Antigravity Agent

## 1. File Size & Line Limit
- **Strict Line Limit**: Keep every code file modular with a **maximum of 400 to 500 lines per file** (ideal range: 150–350 lines).
- **Subcomponents & Modals**: Extract modals, tables, forms, and secondary panels into separate files in a `components/` subfolder rather than writing monolithic 1,000+ line files.
- **Benefits**: Ensures fast AI processing, minimal token usage, zero hallucination, high precision, and clean code maintenance.

## 2. Aesthetics & Design System
- Maintain clean, modern, state-of-the-art UI with rich color palettes, rounded glassmorphism cards, micro-animations, and clean dark mode support.
